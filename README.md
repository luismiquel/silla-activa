# SillaActiva

Aplicación web accesible de ejercicios suaves realizados completamente sentado.

## Características
- 54 ejercicios en silla organizados en 9 categorías.
- Tres niveles de intensidad: suave, medio y fuerte.
- Tres planes guiados de 7 días.
- Temporizador, descansos y guía por voz en español.
- Ilustraciones SVG animadas.
- Opciones de alto contraste y letra grande.
- Calendario, estadísticas y progreso guardados en el navegador mediante localStorage.

## Uso
Abre [la aplicación](https://luismiquel.github.io/silla-activa/) desde un navegador moderno. No requiere instalación ni cuenta.

## Publicación
El proyecto está preparado como una página estática. Para publicarlo con GitHub Pages:
1. Entra en **Settings** del repositorio.
2. Abre **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama **main** y la carpeta **/(root)**.
5. Pulsa **Save**.

## Aviso
La aplicación ofrece orientación general de movimiento y bienestar; no sustituye el consejo de un profesional sanitario. Adapta cualquier movimiento a tus posibilidades y detente si aparece dolor, mareo o malestar.
